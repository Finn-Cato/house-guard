Guest mode

Guests count as home. The alarm stays disarmed and the away routine waits.

How guest mode works

If any of you are home, the lights stay as they are. When you leave, the home remains occupied. Enabling guest mode while everyone is away runs the usual arrival actions, including selected lights and automatic unlocking. The alarm is always disarmed.

Everyone with “Receive push notifications” is notified when guest mode is switched on or off and when the last resident leaves. Night mode waits while guests are home. Switch guest mode off when they leave; if nobody else is home, the usual away routine starts.

Night mode activation

Control night mode with a Homey device: Add device → House Guard → Night mode. On starts night; off starts morning. The switch automatically follows your home’s status.

When does night start?

You can always start night mode from Home or your own Flow.

Homey’s zone activity includes subzones. Door and window contacts can also keep an area active. Choose recipients under People; only those home and awake receive questions. A person already asleep does not prevent night mode for the others. The alarm must be disarmed. Requires an API key under Settings.

Night question replies

Yes starts immediately. No reply starts night mode at the deadline if the area is still quiet and someone is home. A no cancels.

Selected night residents who are home are always set asleep when night mode starts. Choose night residents under People.

Night mode deactivation

Choose how morning starts and what happens when someone wakes up or arrives home at night.

When does morning start?

At this time, selected night residents who are home are set awake and the morning routine starts.

Morning time also ends “Skip automatic night tonight”. If scheduled morning is disabled, this time does not start the morning routine.

Morning starts only when a resident is home. The night alarm requires someone home and asleep. When everyone leaves, the full alarm arms if alarm features are enabled. Guest mode keeps the alarm disarmed.

Start morning on motion (optional)

For example: Start morning when motion is detected in the kitchen after 06:00. Choose a sensor and time window before enabling this feature.

When the home is in night mode and someone is home, the night alarm is disarmed, selected residents at home are set awake and the usual morning actions run. No extra Flow is needed.

How motion morning works

Morning starts once per night on new motion after the sensor has been inactive. This disarms the night alarm even if normal morning disarming is disabled under Alarm.

The away alarm, triggered alarms and entry delays are not cancelled. Motion morning does not start in guest mode. Requires an API key under Settings. A fixed morning time is a separate option.

Arrival at night

People already at home keep their sleep status. Choose disarming on arrival under Alarm.

Use your own wake-up Flows

For the whole home: Use House Guard → Set House Guard mode → Morning in a Flow or Advanced Flow. For individual wake-ups, use Homey’s presence cards to set a person awake. House Guard follows sleep status and can disarm when the first person wakes, as selected under Alarm.

Disable scheduled morning here if your own Flows should choose the time. You can also add “Start existing Flow” to the morning routine for lights, music and other wake-up actions.

Welcome lights

Choose door opening or motion to turn on welcome lights. The sensor must react within ten minutes of the first arrival. The lights turn on once if it is dark enough.

0 means no extra wait here. Any delay on the action itself is added.

A missing or stale light reading sends no lighting command.

Applies from sunset to sunrise, including after midnight. Uses Homey’s location. No light sensor is needed. Your API key must be ready under Settings.

Guest mode

Guests count as someone home. The alarm stays disarmed and lights stay on when the last resident leaves. Enabling guest mode in an empty home runs normal arrival actions. Switching it off in an empty home starts the normal away routine.

Recommended: Add the “Guest mode” device in Homey: Add device → House Guard → Guest mode. Use it to switch guest mode on and off.

Push is sent automatically when guest mode switches on or off and when the last resident leaves guests home alone. Choose recipients with “Receive push notifications” under People. You do not need to add notification actions here.

Use the routines below only for custom extra actions when guest mode switches on or off, such as a Flow or spoken message.

Alarm

House Guard monitors selected sensors directly. Notifications and actions brings together push, cameras, audio, lights and your actions for each alarm event.

House Guard alarm

The night alarm requires someone home and asleep. Test notifications under Notifications and actions without triggering the alarm.

When should the alarm be armed?

These choices control the alarm directly. Routine checkboxes only control extra actions. Requires the House Guard alarm to be enabled.

The full away alarm always arms when all selected residents are confirmed away and guest mode is off. Your usual delays apply. “Start away mode” sets all selected residents away. After silencing, the away alarm arms again if the home is still empty.

Select people under People. The night alarm uses sensors marked “Night” under Sensors. Confirmation delays also apply to away and arrival actions. Choose alarm entry/exit delays under Sensors. Arrival at night disarms the alarm without an arrival delay when “Set only the arriving person awake” is selected. Other people keep their sleep status.

Changes are saved automatically and apply from the next event. They do not change the current alarm mode immediately. Guest mode always keeps the alarm disarmed.

Alarm panel in Homey

Optional: Add a device via Add device → House Guard → Alarm panel to view status and silence the alarm from Homey. The alarm also works without this device.

Alarm sensors

Entry and exit delays

Sensors marked “Delayed” give you time to disarm on arrival.

How sensor selections work

Choose which sensors apply for away and night. Sensors active during arming are temporarily excluded. The remaining sensors arm, and push lists the sensors that are waiting. They are included automatically once inactive. Unknown or unavailable sensors prevent arming and are shown as errors.

Choose recipients under People and connect to Homey under Settings for push notifications.

Robot vacuum and sensor exclusions from Flows

Use House Guard → Disable alarm sensor in a Flow before the robot starts, and Enable alarm sensor when it finishes. Choose full alarm (away) or partial alarm (night) in each card. The exclusion persists until enabled again, including after restarts. Your basic selections are preserved. When enabled again, the sensor waits for an inactive/closed state.

Front door

Yale is controlled directly by the app’s routines. Unlocking requires fresh presence for the arriving person and a confirmed disarmed alarm. After 60 seconds without confirmed lock status, an unknown outcome is logged.

Garage door

Requires a known open garage door and confirmation that nobody at home is asleep. One command is sent, without blind retries, then status is checked. Switch automatic closing off above when you do not want it, for example in winter.

Fire and water

Round-the-clock monitoring, including when the intrusion alarm is off and guests are home.

API key

The Homey API key gives direct access to selected Flows, notifications, Sonos and sleep status.

Create a key in Homey’s web app → Settings → API keys. Choose full Flow access, not just viewing or starting. The key is saved automatically when you paste it or leave the field. It is never shown again or included in exports.

Checking access sends no notifications or device commands.
